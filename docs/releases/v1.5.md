# AudioVisualizer v1.5

## 下载

`AudioVisualizer-1.5.apk`（约 22 MB）

- 适用系统：Android 10 及以上（`minSdk 29`）
- 请**横屏**使用，竖屏未适配
- 与 1.0 ~ 1.4 签名相同，可直接覆盖安装

## 本次更新

### 变更 —— 音频来源默认改为「屏幕录制捕获」

**「屏幕录制捕获」重新定为默认**。具体说明请查阅应用设置页面。

### 新增 —— 「关于」页检查更新

手动点一下即可查询 GitHub Releases，会显示远端版本号，有新版本时可展开更新说明、
直接跳到下载页。

### 新增 —— 每个部件都能单独调外观

新增了各部件可以调整的选项

- **字号**（曲目信息 / 歌词）
- **显示增益**（频谱图）
- **锁定 1:1**（专辑封面）
- **填充颜色**：十六进制输入框 + 实时预览 + R / G / B 三根滑杆，互为镜像
- **整体不透明度**

### 新增 —— 布局导出 / 导入

「版式预设」里可以把整套布局导出成一段纯文本，用于其他设备上再次导入

### 变更 —— 设置项细节

- 滑杆的数值可以**点击直接输入**。

### 移除

- 「接口」页的「接口探测（诊断）」卡片（那是排查元数据读不到时用的临时工具）。
