# AudioVisualizer v1.4

## 下载

`AudioVisualizer-1.4.apk`（约 22 MB）

- 适用系统：Android 10 及以上（`minSdk 29`）
- 请**横屏**使用，竖屏未适配
- 与 1.0 ~ 1.3 签名相同，可直接覆盖安装

## 本次更新

### 新增

- **保存当前布局为预设**。
  微调完各部件的位置 / 尺寸 / 显隐之后，可以把这一整套存下来，以后一键切回，
  不用每次重新拖。
  - 新建时会询问**名称**与**备注**（备注显示在名称下面那行灰字里）。
  - 两者都留空也行：名称自动叫「用户预设 - X」（X 取已用过的最大编号 +1，不会撞名），
    备注自动填创建时间。
  - 用户预设可以随时删除。删掉的正好是当前在用的那个时，会自动切回默认预设。
- **「关于」页补充应用信息**：应用名称、版本（含 versionCode）、包名、SDK 范围。
  这些都在运行时从系统读取，不会出现界面显示与实际安装版本不一致的情况。

### 变更

- 两个内置预设更名为 **「默认：歌词在右上」**、**「默认：歌词在封面下方」**，
  与用户自己保存的预设区分开。

## 主要功能

| 模块 | 说明 |
|---|---|
| 频谱 | 32 段对数分频；FFT 1024 点 + Hann 窗，指数平滑 + 峰值保持 |
| 波形 | 实时时域波形 |
| 电平表 | 左右声道 dBFS 柱状表 + 准峰值线，压到极限时亮削顶红线 |
| 专辑封面 | 整屏虚化封面作背景 |
| 歌词 | LRC 解析，支持翻译行，随播放进度逐行高亮 |
| 播放控制 | 播放列表 / 上一首 / 播放·暂停 / 下一首，可点选切歌；无操作时自动淡出（0–60 秒可调） |
| 背景粒子 | 随音频能量起伏的粒子场，参数可调 |
| 版式 | 2 个内置预设 + 自定义预设（可保存 / 删除）；每个部件的锚点 / 偏移 / 缩放单独可调，支持整体等比缩放 |
| 拖动实时预览 | 调整任意滑块时整页透明，悬浮 HUD 实时显示当前效果 |

## 安装

1. 下载下方的 APK。
2. 在系统设置里允许「安装未知来源应用」，然后安装。
3. 首次运行需要授予**「允许录制或投射」**权限 ——
   该权限用于抓取正在播放的音频，**不会录屏**。

> 如果之前装的是 debug 版本，需要先卸载再安装
> （签名不同无法覆盖，卸载会清掉全部设置）。

## 已知限制

- **仅适配网易云音乐**。元数据走网易云对外声明的车机版 `MediaBrowserService`
  （`com.netease.cloudmusic/.module.ucar.UCarService`），
  其他播放器需要在源码里改一个包名常量。
- **没有循环模式按钮**。网易云没有通过任何标准接口暴露循环模式，
  平台侧的相关 API 在 Android 16 上也不存在。
- 设置里的调试页包含诊断信息，普通使用不需要碰。
