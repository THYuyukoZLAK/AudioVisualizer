# AudioVisualizer v1.3

> 首个公开发布版本。

## 下载

`AudioVisualizer-1.3.apk`（约 22 MB）

- 适用系统：Android 10 及以上（`minSdk 29`）
- 请**横屏**使用，竖屏未适配
- 与 1.0 / 1.1 / 1.2 签名相同，可直接覆盖安装

## 本次更新

### 新增

- **「关于」页新增 GitHub 仓库入口**。设置 → 关于 → GitHub 仓库。

### 改进

- **频谱与电平的标尺拆成两个独立开关**。
  以前一个开关同时管两处，但两者量纲不同 —— 频谱标的是「相对满度的百分比」，
  电平标的是真 dB；用途也不同，频谱看相对起伏、电平看有没有过载。
  现在在「设置 → 外观」里各管各的。
- **电平表的峰值线改成「准峰值」，顶到满量程时亮红线**。
  原先峰值取「整块的最大绝对值」，而这个量在音乐上几乎必然贴着满量程
  （数字母带峰值本来就压到 -1~0 dBFS），于是峰值线的保持期被无限刷新、
  回落分支永远走不到 —— 结果是一条钉死在 0 dB 不动的线，没有读数价值。
  现在改用 3ms 子窗 RMS 的最大值，它会跟着鼓点起伏；
  真顶到满量程时，在 0 dB 位置亮一条红线作为过载提示。

### 修复

- **设置页滚动时会误触发「拖动实时预览」**。
  在设置页竖向滚动时，若手指恰好从某根滑杆上起手，整页会短暂变透明。
  现在先判断手势方向，再决定要不要进入预览状态。

## 主要功能

| 模块 | 说明 |
|---|---|
| 频谱 | 32 段对数分频；FFT 1024 点 + Hann 窗，指数平滑 + 峰值保持 |
| 波形 | 实时时域波形 |
| 电平表 | 左右声道 dBFS 电平，带峰值保持 |
| 专辑封面 | 整屏虚化封面作背景 |
| 歌词 | LRC 解析，支持翻译行，随播放进度逐行高亮 |
| 播放控制 | 播放列表 / 上一首 / 播放·暂停 / 下一首，可点选切歌；无操作时自动淡出（0–60 秒可调） |
| 背景粒子 | 随音频能量起伏的粒子场，参数可调 |
| 版式 | 三种预设 + 每个部件的锚点 / 偏移 / 缩放单独可调，支持整体等比缩放 |
| 拖动实时预览 | 调整任意滑块时整页透明，悬浮 HUD 实时显示当前效果 |

## 安装

1. 下载下方的 APK。
2. 在系统设置里允许「安装未知来源应用」，然后安装。
3. 首次运行需要授予**「允许录制或投射」**权限 ——
   该权限用于抓取正在播放的音频，**不会录屏**。

> 如果之前装的是 debug 版本，需要先卸载再安装
> （签名不同无法覆盖，卸载会清掉全部设置）。

## 已知限制

- **仅适配网易云音乐**。元数据走网易云对外声明的车机版 `MediaBrowserService`
  （`com.netease.cloudmusic/.module.ucar.UCarService`），
  其他播放器需要在源码里改一个包名常量。
- **没有循环模式按钮**。网易云没有通过任何标准接口暴露循环模式，
  平台侧的相关 API 在 Android 16 上也不存在。
- 设置里的调试页包含诊断信息，普通使用不需要碰。
